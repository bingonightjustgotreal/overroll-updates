Roundy source and build files
===============================

To run the source version, first change to this folder and run:

    npm start

To rebuild the Roundy Windows installer from the source, run:

    npm run build:win

To clear this game's local progress and open it as a new player, run:

    npm run reset-player

Google sign-in setup instructions are in GOOGLE_SIGN_IN_SETUP.md.
